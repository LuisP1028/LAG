## 2. Key Architectural Deliverables in This Run

1. **GraphRAG Subgraph Retrieval & Natural Language Routing (Tickets 001–004):**
   - Formalized the replacement of brittle text-to-cypher generation with a generalized **Graph-Augmented Retrieval Generation (GraphRAG)** pipeline.
   - Grounded directly against empirical subgraphs captured from the live Neo4j database:
     - Real-world patient query: *"I am from Wisconsin, survived breast cancer, need lymphedema supplies, I'm on Medicare"* resolves deterministically to `ICD10-I97.2`, `JURIS-DME-B (CGS)`, `HCPCS-A6522`, and Wisconsin allowable reimbursement rates (`$290.47` / `$58.09` coinsurance).
     - Empirical proof: [`neo4j_workflow1_patient_routing_subgraph.json`](assets/20261013T025302-800-gxuw/neo4j_workflow1_patient_routing_subgraph.json).
2. **3D Halftone Visualizer & Blueprint HUD Specifications (Tickets 005–006 & `visualization.md`):**
   - Defined the high-contrast technical blueprint aesthetic: Prussian navy void (`#0a1128`), electric amber nodes (`#ffb703`), screen-space halftone dot shading, and optical depth-of-field bokeh.
   - Synchronized canvas bus: GraphRAG retrieved paths are directly emitted to the 3D canvas, illuminating active multi-hop lineages and dimming unrelated entities.
3. **Strict Invariant Guardrails & Zero-Orphan Policy (Ticket 007):**
   - Rejection of passive fallback clusters: any entity lacking an unbroken path to a root policy triggers a fatal `GraphValidationError`.
   - Sub-second performance SLA: Neo4j topological expansion $<20\text{ms}$; end-to-end response and canvas highlighting $<1.5\text{s}$.
4. **Pipeline Merge Diagnostic:**
   - Similar to run `20261012T231057-024-zqga`, the automated Sandcastle merge encountered concurrent file creation conflicts between `plan-scan-1` and `plan-scan-2` on three asset filenames (`neo4j_workflow1_patient_routing_subgraph.json`, `neo4j_workflow2_coverage_policy_bridge.json`, `neo4j_workflow3_cross_policy_lineage.json`). 
   - All commits (`d9ba82f`, `c1005ad`, `294da71`), assets (34 files), scan reports, wayfinder maps, tickets, and execution logs were safely extracted, de-conflicted, and preserved in this directory.
